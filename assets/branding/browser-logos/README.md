# Logo browser

Logo resmi Brave, Google Chrome, dan Mozilla Firefox, ukuran 512x512, dari koleksi
[alrra/browser-logos](https://github.com/alrra/browser-logos) (`src/<browser>/<browser>_512x512.png`).

Semua logo dan merek dagang ini milik pemiliknya masing-masing (Brave Software, Google,
Mozilla). TGOS memakainya hanya untuk menunjukkan browser mana yang dipilih di halaman
pilihan browser AME Wizard.

`tools/make-option-images.py` membuat `src/Images/<browser>.png` (128 piksel) dari file di
sini.
